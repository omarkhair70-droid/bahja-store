## Experience

Bahja explores an Arabic/RTL commerce direction for handmade products with:

- branded category and collection discovery;
- product-detail flows;
- cart-style selection and checkout;
- custom-order direction;
- WhatsApp conversion and handoff;
- mobile-first storefront composition.
